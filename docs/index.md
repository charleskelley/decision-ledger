DecisionLedger provides a structured pipeline for evaluating, governing, and
auditing AI decisions with deterministic enforcement and full replay capability.
The reference implementation (ATO Reasoner) is a real-time ATO/identity risk
decisioning pipeline using a hybrid ML scorer and LLM policy gate architecture.
