# Assistant Reply Practice
Version 1.0 | Effective: 2026-03-01

> Synthetic practice note for the DecisionLedger text mock. It describes an
> imaginary bank's assistant team and carries no real policy content.

## 1. Purpose

MT-PRAC-REPLIES sets how the assistant team handles the messages customers
send most often, so that a customer who asks for something simple gets an
answer at once and a person spends time only where a person adds something.

## 2. General Questions

Questions about opening hours, fees, interest rates, statements, or branches
are answered automatically from the help center's published content, with
no review. The automated reply links the help center page it quotes, so the
customer can read the rest.

## 3. Contact Detail Changes

A request to change an address, phone number, or email address is confirmed
with a step-up identity check before anything changes: the customer approves
the change in the bank's app, on a device already registered to them, and
only once that check succeeds is the change processed automatically.

## 4. Hardship Messages

A message that states financial hardship MAY receive the automated
hardship-assistance reply right away, without review: the reply links the
payment-plan form and gives the hardship team's phone line. Holding these
messages for an agent is not required, and it delays help the customer
asked for.
